# About Me

I'm pursuing a Master's in **Information Systems (Data Science)** at **Pace University**.

My interests lie in building end-to-end data solutions—from collecting and transforming raw datasets to creating reliable analytical models and executive dashboards.

I enjoy designing data workflows that emphasize:

- Data Quality
- Automation
- Scalability
- Performance
- Reproducibility

Rather than focusing on a single tool, I enjoy engineering complete analytics ecosystems that enable organizations to make confident, data-driven decisions.
